Problem

The module earns its keep, but its interface exposes a multi-call protocol: both callers must know HEAD timing, recovery flags, commit outcomes, and when to observe the final HEAD.

Solution

Absorb observation, evaluation, optional commit, and final-HEAD reporting into the Git policy module; callers retain their checkpoint transitions.

Deletion test: deleting the module spreads selector matching, staged-set verification, and commit behavior across both callers; deepening it increases locality without adding a seam.

  • • Tests hit one interface
  • • Callers stop sequencing Git
