# Treat log.md as a bare log: drop the header and the list dash

## Ticket

> Maybe `log.md` should really be treated as a log: remove the heading, so `open-thread` just creates the empty file, and remove the `-` prefix from every line, given that it is a log and every line is a log entry.
>
> The log-line format lives in four copies (`suite/shared` plus the `discussion`, `spec`, and `resolve-pending-decisions` skills), and `thread.md`, `open-thread`, and the glossary's *log entry* definition describe the current shape, so the change is a sweep across all of them.
>
