# Rename change back to spec and mark old threads as history in the discussion skill

## Intent

The recent artifact-model rework (thread `2026/09/20-1049-artifact-model-rework`, landed in the latest commits) renamed the spec to "change". "Change" is judged too generic a term, so the rename is to be reverted: what is now called "change" becomes "spec" again.

Alongside that, the discussion skill is to state clearly that old threads should generally not be read unless the user asks for it, because they are only history.
