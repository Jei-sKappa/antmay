# Preserve uncertainty when composing a thread's intent

## Ticket

> When `open-thread` restructures additional context into an intent section, it can strengthen tentative language into a requirement. For example, “I'm thinking to use the frontmatter fields” became “The seed's conditional metadata should use frontmatter fields.”
>
> This changes an option the user is considering into a settled direction and adds certainty the user did not supply. The composed intent needs to preserve the modality of the original wording, so tentative ideas remain tentative.
