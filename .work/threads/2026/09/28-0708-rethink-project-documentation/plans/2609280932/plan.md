# Plan: Keep the project layer small

## Objective

Implement the suite side of the change `spec.md` designs. The project layer is reduced to decision records, the glossary, the agents files and the roadmap indexes. A record, glossary term or agents-file change enters it only as a `document` log entry the user accepted when a discussion closed. `spec` drafts delta documents from those entries alone. `close-thread` keeps agents files under a 1,000-word ratchet and refuses to close on an agents-file passage the thread's work made false. The descriptive kinds (product behavior, architecture description) and `consult-descriptions` are retired from the suite, from its registrations and from the maintainer and user-facing documents.

## Context

- **What the implementation does not do.** The thread's `delta/` carries every change to this repository's own project layer: the two PDRs, the glossary edit, the root and suite `AGENTS.md` edits, and the deletes of `docs/product/method.md`, `docs/architecture/suite.md` and PDR 2609230721-thread-design-document-is-the-spec. `close-thread` lands them at close. No task edits `AGENTS.md`, `CLAUDE.md`, `suite/AGENTS.md`, `suite/CLAUDE.md`, `docs/glossary.md`, `docs/product/method.md`, `docs/architecture/suite.md`, or anything under `docs/adr/` or `docs/pdr/`. Each of those is a delta target, and its recorded blob hash must still match when the thread closes. Some acceptance criteria are therefore met only at close. The last task checks that the delta is ready to land.
- **Where suite text changes.** Canonical shared references live under `suite/shared/references/`. The copies under each skill's `references/` are generated by `node scripts/sync-shared-references.mjs`, run from `suite/`, and are never edited by hand. A copy the manifest stops declaring is an orphan and is deleted by hand, as the header of `suite/shared/manifest.yaml` instructs.
- **Standing gates.** Every task that touches `suite/` runs these from `suite/` before it ends: `node scripts/sync-shared-references.mjs`, `node scripts/check-skill-text.mjs` and `node scripts/check-marketplace-skills.mjs`. `check-skill-text` fails on a skill-local path without the `<skill_path>/` prefix, on ``per `<skill_path>``, and on any fence line with leading whitespace. For a command inside a list item, use inline code rather than a fenced block.
- **How shipped text is written.** Follow `suite/authoring/` (the format skeleton in `shared-references.md`, the Inputs template and dead-concept test in `body-structure.md`, write boundaries in `side-effects.md`) and `docs/documentation-rules.md`. Describe the current state only. Keep a negative sentence only when it guards against something a fresh reader would plausibly do.
- **Degrees of freedom this plan pins.** `discussion` reads the decision test and the glossary admission test from manifest-declared copies of the two formats (task 1). Its closing offer is a new step 8 (task 4). `close-thread` works out what the thread changed from git: the diff from the parent of the commit that added this thread's `seed.md` to the working tree, plus untracked files, plus every delta document's target, plus the folders those paths sit in (task 7). Wording and section order stay the implementer's, within the conventions above.
- **CLI drift.** Removing `consult-descriptions` changes the skill list `cli/src/pipeline/documentation.test.ts` reads. Task 10 records this drift in the implementation report and leaves `cli/` alone.
- **Task order.** Tasks 1–3 rewrite the shared references. Tasks 4–9 rewrite the skills that read them. Task 10 retires `consult-descriptions` and deletes the two retired formats once nothing declares them. Task 11 updates the maintainer and user-facing documents and runs the whole-change checks.

## Global Constraints

- `cli/` is not touched (root `AGENTS.md`, `## The CLI is on hold`). Removing `consult-descriptions` changes the published skill list that `cli/src/pipeline/documentation.test.ts` holds the `cli/README.md` stage table to. That is drift for the realignment pass to handle, and nothing in `cli/` is edited here.
- Hand-edited copies under a skill's `references/` are never written. Canonical sources change under `suite/shared/references/`, and `node suite/scripts/sync-shared-references.mjs` regenerates the copies.
- Shipped content stays project-free and describes the current state only, with no "Y, not X" contrast (`docs/documentation-rules.md`).
- 2609230721-thread-reading-rule-in-every-skill-inputs stays where it is. 2609230721-thread-design-document-is-the-spec is deleted by `delta/docs/pdr/2609230721-thread-design-document-is-the-spec.md`, because its stated reason rests on standing behavior living in the delta, which this change removes.
